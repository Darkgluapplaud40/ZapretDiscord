> ### АНТИВИРУСЫ
> Антивирус может отреагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик — этот компонент необходим для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В таком случае файл удаляется и переносится в карантин. Название обнаружения обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. В Kaspersky, например, есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете настройки исключений, предпочтительно добавить исключение. При сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS. Выберите любой вариант, кроме "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках ОС — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать неправильно

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и активируйте флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Найти рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Добавить стратегию в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии вручную

  Такой запуск подходит для проверки различных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно вам**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Значение в скобках показывает, включена функция или выключена.
  - **`IPSet Filter`** — изменить режим обхода сервисов, перечисленных в `ipset-all.txt`.  
  Эта настройка полезна при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках отображается активный режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — проверяется принадлежность IP списку
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить типичные причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной потери работоспособности
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который выполняет обход. Его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните в ней команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого окна блокнота
  - С правами администратора откройте текстовый файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные записи
  - Сохраните файл и снова проверьте подключение. При отсутствии результата убедитесь, что изменения действительно записались.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Darkgluapplaud40/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Со временем отдельные стратегии могут переставать работать.**
> Стратегия способна работать некоторое время, а затем перестать обходить блокировку после её обнаружения.
> В репозитории есть много разных вариантов. Если готовые настройки не помогают, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результат `service.bat` -> `Run Diagnostics` и убедитесь, что там нет ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP-адресов

- Проверьте остальные варианты (**`ALT`**, **`FAKE`** и другие)

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и другие данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при обнаружении ошибок исправьте их, затем в конце выберите Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если в правом нижнем углу есть флажок разблокировки, установите его, нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска, не используя пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка в панели задач и попробуйте другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. В противном случае обход может повлиять на ресурсы, которые вы не собирались фильтровать.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Определите имя службы командой в командной строке Windows. Открыть её можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив найденное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- Дополнительная информация есть в [#251](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Сначала убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузер тоже не подключается, по очереди протестируйте все стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Darkgluapplaud40/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Не работают игры

Игры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- в `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Поэтому не оставляйте его включённым постоянно. Найдите все IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи от других игроков.

### Не нашли своей проблемы

- Опишите её [в этом разделе](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, это полезно, когда сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, подлежащие исключению
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
