>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройки исключений, предпочтительно добавить исключение; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (Cloudflare может оказаться заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно

2. Скачайте zip- или rar-архив с [последнего релиза](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и отметьте "Разблокировать". Для архивов, загруженных через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в путь без кириллицы и специальных символов

5. Запустите нужный скрипт
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки автозапуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно вам**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, работающих с UDP и TCP-портами выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - включение режима обхода для ресурсов из `ipset-all.txt`.  
  Это помогает при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается выбранный режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP сравнивается со списком
    - `any` - фильтруется любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена выбранного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка обновлений
  - **`Run Diagnostics`** - поиск распространённых причин, из-за которых zapret не запускается или не работает.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном отказе клиента
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не изменилось

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/522)

### Рабочей стратегии нет
- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - Откройте появившийся файл `hosts` в текстовом редакторе, запущенном от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените прежние аналогичные записи
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Darkgluapplaud40/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который работал раньше, может перестать работать после его обнаружения.
> Здесь собрано много разных стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте сообщения об ошибках через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что адрес нужного ресурса присутствует в списке доменов или IP

- По очереди проверьте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце выберите Y
- Удалите старую папку с zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа доступна кнопка разблокировки, нажмите её, затем `Применить` и `ОК`
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если соединение не работает, закройте программу через значок замка на панели задач и выберите другую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе обход может повлиять на неожидаемые ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё присутствует в службах

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Проверьте все остальные стратегии, особенно если выбранная раньше больше не работает.
- См. также [#251](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Вызовите `service.bat` -> `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord и выясните, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если браузер тоже не подключается, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Darkgluapplaud40/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учтите: режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Найдите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Создайте описание проблемы [здесь](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить список ресурсов для обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - отдельные IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
